# app/assets/

## このディレクトリには何が入っているか
サイトに載せる前に、加工が必要なファイルが入っています。CSS（見た目の指定）と、部品の中で使う画像（ロゴ）です。

## なぜこのディレクトリが必要か
CSS は、複数のファイルを1つにまとめたり、圧縮したりしてから公開します。画像のように加工せずそのまま公開するもの（`public/`）とは扱いが違うので、置き場所を分けています。

部品の中で `src="~/assets/images/logo-white.svg"` のように書いたファイルは、書き出しのときに Nuxt（Vite）が処理し、URL も自動で決めてくれます。そのため、サイトをドメインの直下ではなく一段下の階層に置いても、正しく読み込めます。

## なぜこのディレクトリ名か
Nuxt の慣習です。必ずこの名前でなければいけないわけではありませんが、Nuxt の公式の書き方に合わせています。

詳しくは、`docs/code-conventions.md` の「3.1 名前の由来」を参照してください。
