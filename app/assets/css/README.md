# app/assets/css/

## このディレクトリには何が入っているか
サイト全体に効く CSS が入っています。色・フォント・余白などの値と、すべてのページに共通する基本の見た目です。
**サイト全体の色や文字の大きさを変えたいときは、まずここを見てください。**

## なぜこのディレクトリが必要か
ボタンやヘッダーなど、それぞれの部品の見た目は部品のファイルの中に書いています。一方で、サイト全体で共有する色や基本のルールは、1か所にまとめておかないと、あちこちに同じ値を書くことになってしまうためです。

## なぜこのディレクトリ名か
このプロジェクトで決めた名前です。CSS の置き場所なので css にしています。
