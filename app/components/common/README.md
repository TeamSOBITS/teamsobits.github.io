# app/components/common/

## このディレクトリには何が入っているか
どのページでも使える小さな部品が入っています。矢印付きのリンクボタン（「More →」など）や SNS のアイコン、文字の演出などです。

## なぜこのディレクトリが必要か
いろいろなページで使い回す部品を、特定のページ専用の部品と混ぜないためです。

## なぜこのディレクトリ名か
このプロジェクトで決めた名前です（検討中）。共通（common）で使う部品という意味です。
