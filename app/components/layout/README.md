# app/components/layout/

## このディレクトリには何が入っているか
すべてのページに出る枠の部品が入っています。ヘッダー、メニュー、言語切替、フッターです。部品の名前は `Site` で始まります。

## なぜこのディレクトリが必要か
どのページにも出る部品と、特定のページでしか使わない部品が混ざらないようにするためです。

## なぜこのディレクトリ名か
このプロジェクトで決めた名前です（検討中）。ページの枠組み（レイアウト）を作る部品なので layout にしています。
