# app/components/research/

## このディレクトリには何が入っているか
研究ページでしか使わない部品が入っています。研究ページの各セクション（GitHub の紹介、研究領域の一覧、各研究領域）が、それぞれ1つの部品になっています。部品の名前は `Research` で始まります。

## なぜこのディレクトリが必要か
ページごとに部品をまとめておくと、「研究ページのこの部分を直したい」ときに探しやすいためです。

## なぜこのディレクトリ名か
このプロジェクトで決めた名前です（検討中）。研究ページ（research）用の部品という意味です。

---

研究ページの構成や更新方法は、`docs/pages/research.md` を参照してください。
