# app/components/people/

## このディレクトリには何が入っているか
メンバーページでしか使わない部品が入っています。1つの欄（教員・博士課程など）、詳しい情報の窓、Robots への案内が、それぞれ1つの部品になっています。部品の名前は `People` で始まります。

## なぜこのディレクトリが必要か
ページごとに部品をまとめておくと、「メンバーページのこの部分を直したい」ときに探しやすいためです。

## なぜこのディレクトリ名か
このプロジェクトで決めた名前です（検討中）。メンバーページ（people）用の部品という意味です。

---

メンバーページの構成や更新方法は、`docs/pages/people.md` を参照してください。
