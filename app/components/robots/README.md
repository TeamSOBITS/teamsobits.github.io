# app/components/robots/

## このディレクトリには何が入っているか
ロボット紹介ページでしか使わない部品が入っています。目次と、ロボット1台分の紹介が、それぞれ1つの部品になっています。部品の名前は `Robots` で始まります。

## なぜこのディレクトリが必要か
ページごとに部品をまとめておくと、「ロボット紹介ページのこの部分を直したい」ときに探しやすいためです。

## なぜこのディレクトリ名か
このプロジェクトで決めた名前です（検討中）。ロボット紹介ページ（robots）用の部品という意味です。

---

ロボット紹介ページの構成や更新方法は、`docs/pages/robots.md` を参照してください。
