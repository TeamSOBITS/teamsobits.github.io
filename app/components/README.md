# app/components/

## このディレクトリには何が入っているか
画面の部品（コンポーネント）が入っています。ヘッダー、ボタン、トップページの各セクションなどです。ページは、これらの部品を組み合わせて作ります。

部品は使われる範囲によって、さらにディレクトリを分けています。
- `layout/`：すべてのページに出る枠（ヘッダー・フッターなど）
- `common/`：どのページでも使う小さな部品
- `home/` など：そのページでしか使わない部品

## なぜこのディレクトリが必要か
1つのファイルにページ全体を書くと長くて読みにくくなるので、見た目のまとまりごとに部品に分けています。

## なぜこのディレクトリ名か
`components` は Nuxt の決まりです。ここに置いた部品は、他のファイルからそのまま使えます。中のディレクトリの分け方は、このプロジェクトで決めたものです（検討中）。
