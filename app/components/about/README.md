# app/components/about/

## このディレクトリには何が入っているか
About ページでしか使わない部品が入っています。About ページの各セクション（概要と起源、プロジェクト、RoboCup、歴史の年表）が、それぞれ1つの部品になっています。部品の名前は `About` で始まります。

## なぜこのディレクトリが必要か
ページごとに部品をまとめておくと、「About ページのこの部分を直したい」ときに探しやすいためです。

## なぜこのディレクトリ名か
このプロジェクトで決めた名前です（検討中）。About ページ（about）用の部品という意味です。

---

About ページの構成や更新方法は、`docs/pages/about.md` を参照してください。
