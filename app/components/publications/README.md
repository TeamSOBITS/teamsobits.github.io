# app/components/publications/

## このディレクトリには何が入っているか
業績ページでしか使わない部品が入っています。目次と、1つの欄（受賞・学会発表など）が、それぞれ1つの部品になっています。部品の名前は `Publications` で始まります。

## なぜこのディレクトリが必要か
ページごとに部品をまとめておくと、「業績ページのこの部分を直したい」ときに探しやすいためです。

## なぜこのディレクトリ名か
このプロジェクトで決めた名前です（検討中）。業績ページ（publications）用の部品という意味です。

---

業績ページの構成や更新方法は、`docs/pages/publications.md` を参照してください。
