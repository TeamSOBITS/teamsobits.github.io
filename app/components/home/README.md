# app/components/home/

## このディレクトリには何が入っているか
トップページでしか使わない部品が入っています。トップページの各セクション（スライドショー、紹介文、代表挨拶、ニュース）が、それぞれ1つの部品になっています。部品の名前は `Home` で始まります。

## なぜこのディレクトリが必要か
ページごとに部品をまとめておくと、「トップページのこの部分を直したい」ときに探しやすいためです。

## なぜこのディレクトリ名か
このプロジェクトで決めた名前です（検討中）。トップページ（home）用の部品という意味です。ページが増えたら、ページごとに同じようなディレクトリを作ります。

---

トップページの構成や更新方法は、`docs/pages/home.md` を参照してください。
