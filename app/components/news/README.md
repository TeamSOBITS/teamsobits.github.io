# app/components/news/

## このディレクトリには何が入っているか
ニュースのページでしか使わない部品が入っています。今は、一覧のカード1枚分の部品だけです。部品の名前は `News` で始まります。

## なぜこのディレクトリが必要か
ページごとに部品をまとめておくと、「ニュースのページのこの部分を直したい」ときに探しやすいためです。

## なぜこのディレクトリ名か
このプロジェクトで決めた名前です（検討中）。ニュースのページ（news）用の部品という意味です。

---

ニュースのページの構成や更新方法は、`docs/pages/news.md` を参照してください。
