# app/composables/

## このディレクトリには何が入っているか
いくつもの部品で使い回す「処理」が入っています。ファイル名と関数名は `use` で始まります。
たとえば `useInView` は「要素がスクロールして画面に入ったかどうか」を調べる処理で、文字の演出、色の帯の演出、円の演出が、画面に入ったときに動き出すために使っています。

ここに入れるのは、**画面には何も表示しないが、Vue の機能を使う処理**です。似たディレクトリとの使い分けは次のとおりです。

| 置き場所 | 何を置くか | 例 |
|---|---|---|
| `app/data/` | ただの値。いつ誰が読んでも同じもの | メニューの一覧、メールアドレス、創設年 |
| `app/components/` | 画面に何かを表示するもの | ボタン、ヘッダー |
| `app/composables/` | 表示はしないが、Vue の機能を使う処理 | 画面に入ったかを見張る、活動年数を計算する |

「Vue の機能」とは、たとえば次のようなものです。
- 値が変わったら画面も自動で書き換わる仕組み（`ref`）
- 部品が画面に出たとき・消えたときに何かをする仕組み（`onMounted`）
- ビルドしたときの値をブラウザに引き継ぐ仕組み（Nuxt の `useState`）

これらは部品の中でしか使えないため、ただの値のように `data/` に書くことはできません。かといって、画面に何も表示しないので部品にする必要もありません。その中間が composable です。

## なぜこのディレクトリが必要か
同じ処理を部品ごとに書いてしまうと、直すときにすべての部品を直さなければいけなくなるためです。1か所にまとめておけば、直すのも1か所で済みます。

## なぜこのディレクトリ名か
Nuxt の決まりです。ここに置いた処理は、import を書かなくても、他のファイルからそのまま使えます。
composable は「組み合わせて使えるもの」という意味の、Vue の用語です。`use` で始める名前の付け方も Vue の慣習です。

---

詳しくは、Vue の公式ドキュメントの「コンポーザブル」（https://ja.vuejs.org/guide/reusability/composables）を参照してください。
