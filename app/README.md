# app/

## このディレクトリには何が入っているか
サイトのソースコード一式です。ページ、画面の部品、見た目（CSS）、処理など、画面に関わるものはすべてここに入っています。

## なぜこのディレクトリが必要か
サイトのコードと、それ以外のもの（設定ファイルや、そのまま公開する画像など）を分けるためです。サイトの中身を直したいときは、まずこの中を見ればよいようになっています。

## なぜこのディレクトリ名か
Nuxt（このサイトを作っている仕組み）の決まりです。Nuxt はこの名前のディレクトリをサイトのコードとして読み込むので、名前を変えると動かなくなります。
