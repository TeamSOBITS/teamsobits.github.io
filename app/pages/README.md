# app/pages/

## このディレクトリには何が入っているか
サイトの各ページが入っています。**ファイル名がそのまま URL になります。** たとえば `index.vue` はトップページ（`/`）です。
日本語版のページ（`/ja/...`）は自動で作られるので、言語ごとにファイルを分ける必要はありません。

## なぜこのディレクトリが必要か
ページを追加するときに、URL の設定を別に書かなくて済むようにするためです。ファイルを置くだけでページが増えます。

## なぜこのディレクトリ名か
Nuxt の決まりです。Nuxt はこのディレクトリのファイルから URL を自動で作ります。

---

ページごとの説明は、`docs/pages/` を参照してください。
