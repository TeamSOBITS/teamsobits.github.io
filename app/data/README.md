# app/data/

## このディレクトリには何が入っているか
プログラムではない「サイトの情報」が入っています。メニューの項目、SNS のリンク、メールアドレス、ニュースの一覧などです。

## なぜこのディレクトリが必要か
情報を更新したい人が、部品のプログラムを触らずに済むようにするためです。また、ヘッダーとフッターの両方に出るメニューのように、同じ情報を何か所にも書かずに済むようにするためでもあります。

## なぜこのディレクトリ名か
このプロジェクトで決めた名前です（検討中）。データ（data）を置く場所という意味です。

Nuxt の決まりのディレクトリではないので、`components/` の部品のように自動では読み込まれません。使うときは `import { NAVIGATION } from '~/data/site'` のように自分で読み込みます（`~` は `app/` を指す記号で、拡張子 `.ts` は省略できます）。
