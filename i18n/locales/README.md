# i18n/locales/

## このディレクトリには何が入っているか
画面に出る文章の翻訳ファイルが入っています。英語用（`/about` などで表示）と日本語用（`/ja/about` などで表示）の2つです。
**文章を直すときは、英語と日本語の両方を直してください。**

## なぜこのディレクトリが必要か
言語ごとに文章をまとめておくと、翻訳の抜けや食い違いに気づきやすいためです。

## なぜこのディレクトリ名か
多言語対応のモジュール（@nuxtjs/i18n）が決めている場所です。locale は「言語や地域の設定」という意味です。

---

詳しくは、`docs/code-conventions.md` の「6. 多言語」を参照してください。
